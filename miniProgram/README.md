# 四博吧唧助手 UI V2

这是基于原 `sucai-ast` 项目重新整理的微信小程序。新版保留原有设备扫描、BLE 连接、文件上传、格式转换、资源下发和历史记录逻辑，重新设计了页面结构、视觉样式和交互状态。

## 页面流程

1. **连接设备**：扫描主服务 UUID 为 `0000A201-0000-1000-8000-00805F9B34FB`、PID 为 `1eAKYY` 的设备。
2. **内容管理**：选择单图、GIF 动图或视频，也可复用、删除历史记录。
3. **内容预览与发送**：文件先上传服务器，再通过 BLE 向设备下发资源地址。

## 保留的业务规则

- 接口根地址：`https://tui.doit.am/second_dimension/`
- BLE 通信服务：`00001910-0000-1000-8000-00805F9B34FB`
- 写特征：`00002B11-0000-1000-8000-00805F9B34FB`
- 通知特征：`00002B10-0000-1000-8000-00805F9B34FB`
- 单图下发类型：`102`
- 动图/视频下发类型：`106`
- 单图自动裁剪、压缩为 `368 × 368`
- 动图和视频使用服务器生成的 `.vpg` 文件
- 设备端下载地址仍按原逻辑由 HTTPS 转换为 HTTP

## 本次整理

- 删除原项目中的演示假设备和未启用的旧页面。
- 去除 AntD Mini、`node_modules` 和 `miniprogram_npm` 依赖，历史记录菜单改为原生实现。
- 修复页面定时器未释放、重新返回连接页不恢复扫描、上传事件解绑拼写错误、回调上下文丢失等问题。
- 修复 BLE 通知开启晚于绑定命令、上传应答被误判为连接成功、多包接收缓存被重复清空等问题。
- 增加连接中、文件处理、服务器上传、设备处理、成功和失败等状态反馈。

## 导入方式

1. 在微信开发者工具中选择“导入项目”。
2. 项目目录选择本文件所在目录。
3. `project.config.json` 暂时保留了原项目 AppID；用于新的小程序主体时，请替换为新 AppID。
4. 在小程序后台将 `https://tui.doit.am` 配置到合法的 request、uploadFile 和 downloadFile 域名。
5. 使用真机测试 BLE 扫描、设备连接和文件下发；开发者工具模拟器不能完整验证蓝牙链路。
